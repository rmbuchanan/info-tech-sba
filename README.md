# info-tech-sba
This program was made for my CSEC Information Technology School Based Assessment for the 2024-2024 academic year.

Prompt:
At the end of the rental period, calculate the balance owed by each client based on the condition of the returned equipment. If all equipment is in good condition and none are missing, the client is not charged any additional cost. If any equipment is damaged or lost, the client must pay an additional cost based on the severity of the damage.
